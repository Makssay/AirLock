# Реальный тестнет-прогон

[English](../LIVE-TESTNET.md) | Русский

На странице `#testnet` работают настоящие Ethereum Sepolia и Portaldot V3. Это общая тестовая казна команды. Для отправки заявки нужен настроенный кошелёк владельца Sepolia outbox; для управления казной нужен отдельный native-кошелёк guardian. Посетители могут смотреть состояние без подключения кошелька.

Страница `#try` остаётся отдельной симуляцией с виртуальными средствами и настоящими Telegram-уведомлениями.

## Что нужно для прогона

1. Запустить отдельный relay и существующий V3 Telegram observer. Сейчас оба процесса работают на машине разработчика и требуют, чтобы она оставалась включённой. Relay читает только отдельный локальный тестовый ключ V3. На Vercel и в облачном playground ключей подписания нет.
2. Подключить native-кошелёк guardian через совместимое браузерное расширение. Запланировать возобновление с прежними лимитами, подождать неизменяемые 300 секунд и активировать его. Перед подписью приложение проверяет сеть, код, адрес guardian, результат симуляции и средства на временный депозит хранения и комиссию.
3. Подключить EVM-кошелёк владельца исходного контракта и выбрать Ethereum Sepolia. Выбрать выплату 0,25, 2 или 4 tPOT и подписать вызов outbox. ETH оплачивает только комиссию в Sepolia. Сама выплата идёт из казны Portaldot.
4. Сохранить хеш. Приложение дождётся шести подтверждений Sepolia и покажет финализированное состояние выплаты на V3. После перезагрузки используется та же заявка. Автоматической замены транзакций нет.
5. Для контролируемого инцидента остановить выплаты и отменить заявку. Для законной крупной выплаты дождаться окончания карантина и выполнить её вручную.
6. Проверить настоящее уведомление в настроенном чате guardian. Открытие бота другим посетителем само по себе не подключает его к реальной казне.

## Текущий блокер

В казне 48,75 tPOT, выплаты остановлены. Последняя проверка показала у guardian 5,01908574072156 native tPOT и требование 11,5245 tPOT временного депозита для планирования возобновления, плюс комиссия и запас. Проверка останавливается до запроса подписи. Вывести средства из остановленной казны для пополнения guardian через этот контракт нельзя.

Проверка всех 165 записей загруженного кода не обнаружила свободного депозита guardian: единственный принадлежащий ему код используется активным контрактом. Код не удалялся, правила казны не ослаблялись.

Новый полный тестнет-прогон остаётся до доступного финансирования. Старые реальные подтверждения и локальные тесты хранятся отдельно. Успешные сборки и проверки не заменяют новые тестнет-транзакции или ручную проверку расширений.

## Запуск relay

```powershell
npm run relay:testnet -- --send-testnet --wallet path/to/relay-wallet.local.json
```

При первом запуске relay запоминает текущий блок Sepolia и следит за последующими событиями. Должен работать только один процесс подписания этим ключом. Не запускайте одновременно старую консоль для отправки relay-транзакций.

Журнал `deployments/testnet-relay.local.json` сохраняется до отправки подписанных байтов. При обрыве связи повторно отправляются только те же байты. Подтверждённый revert автоматически не повторяется. Общий лимит инструкций нового журнала — 10 tPOT; лимит оценки одной relay-транзакции — 5 tPOT с запасом газа 10% и остатком 0,1 tPOT.

Для существующей заявки остановите процесс и добавьте при повторном запуске `--source-hash 0x…`. Не удаляйте журнал для обхода неопределённой транзакции. Подробности и ограничения — в [английской инструкции](../LIVE-TESTNET.md).
